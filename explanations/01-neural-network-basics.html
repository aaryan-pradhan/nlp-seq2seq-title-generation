Neural network basics

What a neural network is, how it computes, and how it learns. Nothing on this page is about language yet: it's the machinery every model in the project runs on.

assignment_spec.pdf · Overview
"In this assignment, we will use Deep Neural Network (DNN) based language models to generate titles for new Wikipedia articles, given the body text."

Before a "language model" can make sense, "deep neural network" has to. This page builds one from scratch: numbers, then layers, then a way of measuring mistakes, then the procedure that reduces them.

Notation used everywhere

1. Vectors and the dot product

A neural network only ever does arithmetic on lists of numbers. The single most important operation on two vectors of the same length is the dot product: multiply matching positions and add everything up.

\[ \mathbf{a} \cdot \mathbf{b} = \mathbf{a}^\top \mathbf{b} = \sum_{i=1}^{d} a_i b_i \]

It's large and positive when the two vectors point in similar directions, near zero when they're unrelated, and negative when they point in opposite directions. That makes it a similarity score. Attention in Part C1 is built entirely on this reading.

Worked example

\(\mathbf{a} = (1, 2, 0)\), \(\mathbf{b} = (3, 1, 5)\): \(\;\mathbf{a}\cdot\mathbf{b} = 1\cdot 3 + 2 \cdot 1 + 0 \cdot 5 = 5\).

Multiplying a matrix by a vector is just many dot products at once: row \(i\) of \(W\) dotted with \(\mathbf{x}\) gives entry \(i\) of the result. So \(W \in \mathbb{R}^{m\times n}\) turns an \(n\)-number vector into an \(m\)-number vector.

2. A linear layer

The basic building block is a linear layer: multiply the input by a matrix of weights, then add a vector of biases.

\[ \mathbf{y} = W\mathbf{x} + \mathbf{b}, \qquad W \in \mathbb{R}^{m \times n},\; \mathbf{b} \in \mathbb{R}^{m},\; \mathbf{x} \in \mathbb{R}^{n},\; \mathbf{y} \in \mathbb{R}^{m} \]

The entries of \(W\) and \(\mathbf{b}\) are the layer's parameters, and the network learns them. This layer has \(m \cdot n + m\) of them. For example, the layer that maps a 600-number vector down to 300 numbers in Part B1 has \(300 \cdot 600 + 300 = 180{,}300\) parameters.

3. Activation functions, and why they're needed

Stacking two linear layers without anything in between gains nothing, because the composition is still one linear layer:

\[ W_2(W_1\mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2 = \underbrace{(W_2 W_1)}_{\text{one matrix}}\mathbf{x} + \underbrace{(W_2\mathbf{b}_1 + \mathbf{b}_2)}_{\text{one vector}} \]

To model anything more complicated than a straight-line relationship, a non-linear activation function is applied to each number between layers. Three appear in this project:

\[ \sigma(z) = \frac{1}{1 + e^{-z}} \in (0, 1), \qquad \sigma'(z) = \sigma(z)\big(1 - \sigma(z)\big) \] \[ \tanh(z) = \frac{e^{z} - e^{-z}}{e^{z} + e^{-z}} \in (-1, 1), \qquad \tanh'(z) = 1 - \tanh^2(z) \] \[ \operatorname{ReLU}(z) = \max(0, z), \qquad \operatorname{ReLU}'(z) = \begin{cases} 1 & z \gt 0 \\ 0 & z \lt 0 \end{cases} \]

Sigmoid \(\sigma\) squashes any number into \((0,1)\), so it behaves like a dimmer switch. The GRU's gates use it on the next page. tanh squashes into \((-1, 1)\). ReLU passes positive numbers through and zeroes negatives. The derivatives (written with a prime, \('\)) are listed because learning depends on them. Notice that \(\sigma'\) is at most \(0.25\) and \(\tanh'\) at most \(1\). That fact is why plain recurrent networks struggle, as the next page shows.

4. A network is layers composed

A "deep" network is several such layers applied one after another. A two-layer example:

\[ \mathbf{z} = W_1\mathbf{x} + \mathbf{b}_1, \qquad \mathbf{a} = \operatorname{ReLU}(\mathbf{z}), \qquad \hat{\mathbf{y}} = W_2\mathbf{a} + \mathbf{b}_2 \]

Running the input through the layers to get the output \(\hat{\mathbf{y}}\) (read "y-hat", the prediction) is called the forward pass. Every model in this project, from the RNN to T5, is this idea with more elaborate layers.

5. A loss: one number that measures wrongness

To learn, the network needs a single number saying how wrong its prediction was. That number is the loss, \(\mathcal{L}\). The simplest example is squared error between a prediction \(\hat{y}\) and the true answer \(y\):

\[ \mathcal{L} = (\hat{y} - y)^2 \]

Language models use a different loss, cross-entropy, because predicting a word means picking one option out of many rather than producing a number. That loss is defined on the next page. Everything below works the same for any loss.

6. Gradient descent: how the network learns

The gradient \(\nabla_\theta \mathcal{L}\) is the vector of derivatives of the loss with respect to every parameter. Each entry says how much the loss would change if that one parameter were nudged up slightly. Stepping every parameter a little in the opposite direction lowers the loss:

\[ \theta \leftarrow \theta - \eta \, \nabla_\theta \mathcal{L} \]

\(\eta\) (eta) is the learning rate, which sets the step size. Too large and the steps overshoot the minimum. Too small and learning crawls. The RNNs in this project use \(\eta = 0.001\). Fine-tuning T5 uses \(\eta = 0.00002\), because its parameters already start somewhere good.

Worked example: one parameter

Model \(\hat{y} = w x\), one training example \(x = 2,\ y = 6\), starting from \(w = 1\), with \(\eta = 0.05\).

\[ \hat{y} = 2,\quad \mathcal{L} = (2-6)^2 = 16,\quad \frac{\partial \mathcal{L}}{\partial w} = 2(\hat{y}-y)\,x = 2(-4)(2) = -16 \] \[ w \leftarrow 1 - 0.05 \cdot (-16) = 1.8 \;\;\Rightarrow\;\; \hat{y} = 3.6,\quad \mathcal{L} = 5.76 \]

The loss fell from 16 to 5.76 in one step. Repeating it gives \(w = 2.28\), then \(2.568\), approaching the best value \(w = 3\).

7. Backpropagation: the chain rule, applied layer by layer

A real network has millions of parameters buried inside several layers, so their derivatives come from the chain rule: if \(\mathcal{L}\) depends on \(\hat{\mathbf{y}}\), which depends on \(\mathbf{a}\), which depends on \(\mathbf{z}\), which depends on \(W_1\), the derivatives multiply along that path.

\[ \frac{\partial \mathcal{L}}{\partial W_1} = \frac{\partial \mathcal{L}}{\partial \hat{\mathbf{y}}} \cdot \frac{\partial \hat{\mathbf{y}}}{\partial \mathbf{a}} \cdot \frac{\partial \mathbf{a}}{\partial \mathbf{z}} \cdot \frac{\partial \mathbf{z}}{\partial W_1} \]

Backpropagation computes these products starting at the loss and moving backwards through the layers, reusing each partial product for the layer before it. Libraries like PyTorch do this automatically: calling loss.backward() fills in the gradient of every parameter. The key point for later: the gradient reaching an early layer is a product of many factors. If those factors are consistently smaller than 1, the product shrinks towards zero.

8. Mini-batches, steps and epochs

Computing the gradient over all ~14,000 articles for every single update would be slow. Instead the data is shuffled and split into mini-batches of \(B\) examples, and the loss is averaged over just that batch:

\[ \mathcal{L}_{\text{batch}} = \frac{1}{B}\sum_{n=1}^{B} \mathcal{L}_n, \qquad \text{steps per epoch} = \left\lfloor \frac{N}{B} \right\rfloor \]

One parameter update is a step. One full pass over all \(N\) training examples is an epoch. The floor \(\lfloor\cdot\rfloor\) applies when a leftover partial batch is dropped (drop_last=True in the RNN code). Part B1 trains on \(N = 13{,}379\) articles with \(B = 8\): \(\lfloor 13{,}379 / 8 \rfloor = 1{,}672\) steps per epoch, for 3 epochs.

9. Adam: gradient descent with memory

Plain gradient descent uses the same step size for every parameter and reacts only to the current batch's noisy gradient. Adam, the optimizer used for every model here, keeps two running averages per parameter:

\[ \begin{aligned} \mathbf{m}_s &= \beta_1 \mathbf{m}_{s-1} + (1-\beta_1)\,\mathbf{g}_s && \text{average gradient (momentum)} \\ \mathbf{v}_s &= \beta_2 \mathbf{v}_{s-1} + (1-\beta_2)\,\mathbf{g}_s \odot \mathbf{g}_s && \text{average squared gradient} \\ \hat{\mathbf{m}}_s &= \frac{\mathbf{m}_s}{1-\beta_1^{\,s}}, \quad \hat{\mathbf{v}}_s = \frac{\mathbf{v}_s}{1-\beta_2^{\,s}} && \text{correct the start-up bias} \\ \theta_s &= \theta_{s-1} - \eta\, \frac{\hat{\mathbf{m}}_s}{\sqrt{\hat{\mathbf{v}}_s} + \epsilon} && \text{update} \end{aligned} \]

\(\mathbf{g}_s\) is the gradient at step \(s\), and the square root and division are element-wise. Defaults are \(\beta_1 = 0.9\), \(\beta_2 = 0.999\), \(\epsilon = 10^{-8}\). The momentum term smooths out batch-to-batch noise. Dividing by \(\sqrt{\hat{\mathbf{v}}}\) gives each parameter its own step size: parameters with consistently large gradients take smaller steps, and rarely-updated ones take larger steps. The bias correction matters only in the first few hundred steps, when \(\mathbf{m}\) and \(\mathbf{v}\) are still close to their starting value of zero.

10. Generalization: training, validation and test data

The goal isn't to do well on the training articles. It's to do well on articles the model has never seen. That's why data is split three ways:

  • Training set: used to compute gradients and update parameters.
  • Validation set: never trained on. Used to check progress and choose settings like the learning rate.
  • Test set: touched only once, at the end, to report final scores. Here it's the 100-article test.csv.

Two failure modes, told apart by comparing the losses:

  • Underfitting: training loss stays high. The model can't even fit the data it's shown, usually because it lacks the capacity, the information, or enough training. Part B2's hierarchical encoder shows exactly this signature.
  • Overfitting: training loss keeps falling while validation loss rises. The model is memorizing training examples instead of learning patterns that transfer.

11. Three training aids that appear in the code

Dropout

During training, each number in a vector is independently zeroed with probability \(p\), and the survivors are scaled up so the expected value is unchanged. At evaluation time dropout is switched off.

\[ \tilde{x}_i = \frac{r_i}{1-p}\, x_i, \qquad r_i \sim \operatorname{Bernoulli}(1-p) \]

\(r_i\) is 1 with probability \(1-p\) and 0 otherwise. Because the network can't rely on any single number always being present, it learns more redundant, robust features, which reduces overfitting. The RNN encoders use \(p = 0.3\) on their word embeddings.

Weight decay

Each step also shrinks every weight slightly towards zero, which discourages the model from relying on a few very large weights. With the "decoupled" form used by the AdamW optimizer in Part C1:

\[ \theta \leftarrow \theta - \eta\,\lambda\,\theta \quad \text{(applied alongside the Adam update, with } \lambda = 0.01 \text{ in Part C1)} \]

Gradient clipping

If one unlucky batch produces a huge gradient, a single step can wreck the parameters. Clipping rescales the whole gradient whenever its length exceeds a threshold \(c\):

\[ \mathbf{g} \leftarrow \mathbf{g} \cdot \min\!\left(1,\; \frac{c}{\lVert \mathbf{g} \rVert}\right), \qquad \lVert \mathbf{g} \rVert = \sqrt{\textstyle\sum_i g_i^2} \]

The direction is kept and only the length is capped. The Part B1 training loop uses \(c = 1.0\).
