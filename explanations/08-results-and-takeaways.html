How big is a meaningful difference? Each score is a mean over 100 articles, so:

\[ \overline{F} = \frac{1}{100}\sum_{k=1}^{100} F^{(k)}, \qquad F^{(k)} \in [0, 1] \;\Rightarrow\; \text{one article changing from 0 to 1 moves } \overline{F} \text{ by } 0.01 \]

A gap of 0.012 (C1 against the best C2 row) is about one article's worth, too little to separate the two on this test set. A gap of 0.17 (GloVe run 1 against hierarchical run 2) is seventeen articles' worth. The per-article scores that a formal significance test would need weren't saved, so this rule of thumb is the most the logs support.

What the evidence supports

1. Pretrained knowledge was the biggest lever

Within Part B, the one upgrade that brought in outside knowledge, GloVe, is the one with clear evidence of helping: lower training loss at every epoch, and the best ROUGE among the B2 runs. Across parts, both pretrained Transformers beat every RNN by a margin (0.33–0.50 → 0.86–0.87) far larger than any measurement difference. The RNN had to learn language and the task from 13,379 articles. T5 only had to learn the task.

2. Added structure helps only if it adds usable information

The hierarchical encoder, as implemented, replaced a GRU summary with one padding-diluted average of the whole article. Training loss rose from 1.30 to 3.12: the model lost the ability to fit even its training data. The two-GRU decoder and beam search, built on top of that encoder, showed no difference that single runs can distinguish from noise, and beam search cost 5.8× the evaluation time. More components didn't mean more capability. What mattered was whether a component gave the decoder better access to the article, and cross-attention in C1 is the component that did.

3. A larger instruction-tuned model matched fine-tuning without any training

Flan-T5-large, never trained on these articles, scored within about one article's worth of fine-tuned T5-small (0.8745 vs. 0.8626 ROUGE-L), and the scoring difference works against it. Scale was decisive: Flan-T5-base, with the same instruction tuning, trailed by 14–24 articles' worth. Prompt wording shifted scores by about five articles' worth, in opposite directions for the two sizes.

4. A comparison is only as good as its measurement

The biggest apparent RNN improvement (0.25 → 0.50) coincides with an evaluation change. Part B and Part C score against different references. C1 and C2 use different stemming. Every row is a single run on 100 articles. None of this overturns lessons 1–3, whose effects are large, but it limits what the smaller gaps can mean.

What would make the comparisons cleaner

Each item follows from a specific note on an earlier page:

  • Score every model with one evaluation function, one reference set (raw titles) and one stemmer setting. B2, C2
  • Append <EOS> to RNN training titles so generation ends by itself, instead of cutting outputs to the reference length. B1
  • Split sentences before removing punctuation, so the hierarchical encoder can average per sentence as specified, and exclude padding from the average. B2
  • Rank beams by log-softmax scores rather than raw logits, and reuse a trained model when testing a decoding change. B2
  • Run each upgrade individually on top of B1, as the spec's report section asks, and repeat runs with different random seeds. B2
  • Mask padded label positions (set them to -100) so T5's loss reflects real title tokens. C1
  • Save per-article scores so differences can be tested properly. This page.
